# Huffman Coding in C

A file compression and decompression program implemented in C using the **Huffman coding algorithm**. The project explores lossless compression, binary trees, linked lists, dynamic memory allocation, file handling, and bitwise operations.

## Overview

Huffman coding is a lossless compression algorithm that assigns variable-length binary codes to symbols according to their frequency of occurrence. More frequent symbols receive shorter codes, while less frequent symbols receive longer codes.

This project implements Huffman coding in C to compress and decompress files, including text files and binary files such as PNG images.

## Features

- **Lossless compression:** Preserves the original file contents.
- **Binary file support:** Designed to process files at the byte level.
- **Frequency analysis:** Calculates the frequency of each byte in the input file.
- **Huffman tree construction:** Builds a binary tree based on byte frequencies.
- **Binary encoding:** Uses bitwise operations to encode data efficiently.
- **File decompression:** Reconstructs the Huffman tree and decodes the compressed data.
- **Custom file format:** Stores metadata required for decompression.

## How It Works

The compression process consists of the following steps:

1. **Frequency analysis:** Reads the input file and counts the occurrences of each byte.
2. **Tree construction:** Repeatedly combines the two nodes with the lowest frequencies to build the Huffman tree.
3. **Code generation:** Traverses the tree to assign a binary code to each byte. Left branches represent `0`, and right branches represent `1`.
4. **Encoding:** Replaces each byte with its corresponding Huffman code.
5. **Bit packing:** Packs encoded bits into bytes to avoid storing each bit as a separate character.
6. **File generation:** Writes the metadata and compressed data to the output file.

During decompression, the program reads the metadata, reconstructs the Huffman tree, decodes the bitstream, and restores the original file contents.

## Using

### Prerequisites

- GCC or another compatible C compiler
- A terminal or command-line environment

### Clone the Repository

```bash
git clone https://github.com/gholandalb/Huffman-coding.git
cd Huffman-coding
```

### Compilation

Compile the source file using GCC:

```bash
gcc huffman.c -o huffman
```

If your source file has a different name, replace `huffman.c` with the appropriate filename.

### Running the Program

On Linux or macOS:

```bash
./huffman
```

On Windows:

```bash
huffman.exe
```

Follow the instructions displayed by the program to compress or decompress a file.

- The decompressor is intended to process files generated by the corresponding compressor.
